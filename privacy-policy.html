Privacy Policy

Thagadur Career Services (OPC) Private Limited

This Privacy Policy outlines how Thagadur Career Services (OPC) Private Limited collects, uses, protects, and handles your personal information when you use our website, mobile application, job portals, or PM-WANI Wi-Fi hotspot services.

1. Personal Information Collection

The Application and Portal collect user personal information required for providing service, including the User's 10-digit Mobile Number (mandatory) and Email Address (optional).

2. Data Sharing with PDO Aggregators (PDOA)

The Application shares the Mobile Number and Email Address with an authorized third party called the Public Data Office Aggregator (PDOA) using secure HTTPS methods. This transmission is required to authenticate users and enable PM-WANI wireless Wi-Fi internet access services.

3. User Device Information

The Application collects user device information such as Device Make and Model, Device Operating System Version, and supported Wi-Fi bands for the purpose of improving user experience, optimizing Wi-Fi network routing, and resolving technical performance issues.

4. Database Security & Statutory Compliance

The Application backend stores user information securely in database systems. The Application may share necessary data with authorized law enforcement agencies to comply with statutory and regulatory mandates of the Government of India.

5. Account Deletion & Rights

The Application provides an option for users to delete their account and personal data. Upon receiving an account deletion request, user data will be permanently removed from the Application backend servers.
